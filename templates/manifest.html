ℹ️ Guide d'Organisation des 3 Clés de Sécurité

Architecture Unifiée

Pour que l'écosystème MCP fonctionne de manière sécurisée et autonome, 3 clés distinctes interviennent entre MELODI ERP, melodi_mcp_server et vos Agents IA :

1. Clé Interne de Service Système ⇄ Système
Variable ERP : MCP_INTERNAL_KEY
Côté Serveur MCP : MELODI_API_KEY

Sécurise les requêtes directes entre le serveur MCP et MELODI (exécution d'outils, webhooks de révocation, synchronisation catalogue).

2. Secret de Chiffrement JWT Signature HS256
Variable ERP : MCP_JWT_SECRET
Côté Serveur MCP : MCP_JWT_SECRET

Clé secrète partagée. Permet à MELODI de signer les jetons des agents IA, et à melodi_mcp_server de valider leur signature et leur expiration (≤ 72h).

3. Clé Infrastructure MCP Intégrée au JWT
Variable ERP : MCP_SERVER_API_KEY
Côté Serveur MCP : MCP_API_KEY

Clé propre à l'instance de melodi_mcp_server. Injectée automatiquement dans les jetons JWT des utilisateurs pour simplifier leur configuration.
