{{ t('dual_auth_title', 'Principe de double authentification') }}
  • X-Internal-MCP-Key : Authentifie le serveur MCP (melodi_mcp_server) auprès de MELODI ERP.

  -H "X-User-MCP-Key: {VOTRE_TOKEN_MCP}" \
  -H "Content-Type: application/json" \
  -d '{"tool_name": "...", "arguments": {...}}'
