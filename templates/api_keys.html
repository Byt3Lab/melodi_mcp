{{ t('integration_headers_title', 'Authentification : En-tête unique Authorization') }}

{{ t('single_header_title', 'Architecture Sécurisée JWT') }}
  • Authorization: Bearer <token> : Jeton JWT auto-porteur contenant votre identifiant utilisateur (user_id), l'identifiant du token (token_id), l'empreinte de la clé MCP (mcp_api_key) et l'expiration (exp).
  • Durée de vie maîtrisée : Validité maximale de 72h. Tout jeton dépassant 72h est automatiquement rejeté.
  • Révocation instantanée : Lors de la suspension ou suppression d'un token dans MELODI, un signal de révocation est immédiatement transmis à melodi_mcp_server.
